# Lab2_OOP
## Військові літаки. Військові літаки можна описати за наступною схемою:
o	Model – назва моделі.
o	Origin – країна виробництва.
o	Chars (має бути декілька) – характеристики: тип (літак підтримки, супроводу, винищувач, перехоплювач, розвідник), кількість місць (1 або 2), боєкомплект (є або ні [для розвідника]), якщо є, то: ракети [0 – 10], наявність радара.
o	Parameters – довжина, ширина, висота (у метрах).
o	Price – ціна (у талерах). Кореневий елемент назвати Plane.
